# Editing AVRFP content

Each public page has one Markdown file in this folder. Saving a file updates the
website immediately; there is no build command.

- Text below a `##` heading belongs to that named page section.
- Repeating cards and FAQ entries use `### Card or question title` headings.
- The text below a card heading is its description or answer.
- Keep the `##` section names unchanged because PHP uses them to place content.
- Markdown formatting such as emphasis, links, and lists is supported.
- Raw HTML is intentionally disabled for safety and layout consistency.
